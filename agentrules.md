# Token Conservation & Concise Output Rules

- **Zero Fluff**: Do not write introductory or concluding conversational text (e.g., "Sure, here is...", "Hope this helps!").
- **Code Only / Diff Mode**: When updating existing code, do NOT output the whole file. Provide ONLY the specific modified functions or unified diffs.
- **No Over-Engineering**: Follow YAGNI strictly. Do not add unused utility functions, speculative interfaces, or redundant inline comments.
- **Context Efficiency**: Do not ask to read files that are not directly related to the active task.
- **Terse Explanations**: If explanations are requested, keep them under 3 bullet points.
